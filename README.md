# kklab-shizuoka-youth-migration

静岡県の若年（15〜29歳）日本人の人口移動を、男女・35市町・年齢・移動先別に可視化したページです。

**公開ページ：** https://katzkawai.org/kklab-shizuoka-youth-migration/

GitHub Pages は `gh-pages` ブランチから配信しています。`main` への push は GitHub Actions（`.github/workflows/sync-gh-pages.yml`）で自動的に `gh-pages` に反映されます。

## 主な知見（2025年）

- 15〜29歳の転出超過は、女性4,069人・男性3,471人。人口1000人当たりでは女性18.6・男性14.4。
- 他都道府県への**転出は男性の方が多い**（男性15,378人・女性12,138人）。一方、**転入は女性が大きく少ない**（男性11,907人・女性8,069人）。
- 20〜24歳で女性の転出超過が男性より864人多いのは、転入が2,038人少ないため。転出はむしろ1,174人少ない。
- 西部（浜松・袋井・湖西）では20〜24歳の男性が転入超過である一方、同年代の女性は転出超過。
- 20〜24歳の性比（女性100対男性）は静岡県110.7、全国105.1。

## データ

| ファイル | 内容 |
|---|---|
| `data/municipalities.csv` | 35市町 × 男女 × 年齢（15〜19／20〜24／25〜29）の転入超過・転入・転出・人口 |
| `data/destinations.csv` | 静岡県から見た46都道府県別の転入超過と転出（男女・年齢別） |
| `data/data.json`, `data/data.js` | ページが読む同じデータ |

出典（いずれも総務省、e-Stat）

- 「住民基本台帳人口移動報告」2025年 年報：表8-2・8-3（都道府県別）、表11-1〜11-3（市区町村別）。日本人移動者。
- 「住民基本台帳に基づく人口、人口動態及び世帯数調査」令和7年1月1日：日本人住民の市区町村別年齢階級別人口（1000人当たりの分母）。

## 再現方法

```sh
pip install openpyxl
python scripts/build_data.py
```

e-Statから原表（Excel）を `scripts/raw/` に取得し、`data/` 以下を生成します。スクリプトには次の検算が入っています。

- 35市町の転入超過の合計が、県外との収支（表8-3）と男女・年齢別に一致すること

また、静岡新聞（2026年9月28日）記事の女性の数値を同一手法で完全に再現できることを確認しています。記事で確認した数値は次のとおりです。

- 浜松市551人、松崎町134.0人／1000人
- 年代別1,146／2,194／729人
- 東京都1,975人、関東4都県への転出6,985人

## 集計上の注意

- 静岡市・浜松市は市計を使っています（区間の移動は含みません）。
- 市町別の収支には、県内の他市町との移動を含みます。
- 伊豆地域の区分は分析上の定義です（熱海・伊東・下田・伊豆・伊豆の国・東伊豆・河津・南伊豆・松崎・西伊豆・函南）。
- 2025年の単年データです。小規模な町の率は変動が大きくなります。
- 住民票を移さない移動は含まれません。
